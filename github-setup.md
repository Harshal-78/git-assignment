## 3. Difference Between Local and Remote Repository

### Local Repository

A local repository is stored on our computer. We use it to create files, track changes, and make commits.

### Remote Repository

A remote repository is stored on an online platform such as GitHub. It allows us to store code online, share projects, and collaborate with other developers.

### Main Difference

A local repository exists on our computer, whereas a remote repository exists on a remote server such as GitHub.
